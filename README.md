A make.fun **news-image-20261119** entry: a deterministic, standard-library-only Python program that publishes a 1024×1024 infographic of the world's news on Thursday 19 November 2026.

## Run it

```sh
python3 main.py
```

The program writes `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`) after checking the PNG signature and byte count. The finished image ships in this repository as `entry.png`, so the run copies those exact bytes; no network, PIL, or other third-party packages are needed.
